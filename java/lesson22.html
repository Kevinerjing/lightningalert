1. Map the characters

A String stores text; char stores one character. For these classroom examples, draw a box for each character before choosing indices.

String str = "Hello!";
// character: H e l l o !
// index:     0 1 2 3 4 5
char letter = 'H';
String word = "H";

Length is 6, but the last index is 5. Spaces and punctuation count. An empty String has length 0 and no valid charAt index. Java String indices count UTF-16 code units; the simple letters in these exercises each use one.

2. Five essential methods

MethodReturn typeExampleResult
charAt(index)char"Hello!".charAt(1)'e'

substring(begin, end)String"Hello!".substring(1, 3)"el"
equals(other)boolean"Hello!".equals("hello!")false

Index rule: charAt uses 0 through length() - 1. substring includes begin and excludes end; its length is end - begin. A substring end may equal length().

String str = "Hello!";
System.out.println(str.substring(0, 6)); // Hello!
System.out.println(str.substring(3));    // lo!
System.out.println(str.substring(2, 2)); // empty line
System.out.println(str.indexOf("z"));   // -1

Before using indexOf in substring, check for -1. Use equals for content, not ==. String length is a method: length(), not length.

5. Find all the errors

Intended task: if the word content is Kevin, print its last character; then print the uppercase word and its first three characters. Find all errors, record the line and correction, and preserve this goal. Number the lines on paper.

public Class Main {
    public static void main(String[] args) {
        String word = "Kevin"
        int n = word.length;
        char last = word.charAt(n);
        if (word == "Kevin") {
            System.out.printLn(last);
        }
        word.toUpperCase();
        System.out.println(word);
        System.out.println(word.substring(1, 4));
    }
}
Reveal the eight checks and corrected code
  1. Class → class (syntax).
  2. Add the missing semicolon (syntax).
  3. length → length() (syntax).
  4. charAt(n) → charAt(n - 1), after ensuring nonempty text (runtime bounds).
  5. == → equals for content comparison (logic; this literal may appear to work because of shared references).
  6. printLn → println (syntax).
  7. Assign the result of toUpperCase (logic).
  8. Use substring(0, 3) for the first three characters (logic).
public class Main {
    public static void main(String[] args) {
        String word = "Kevin";
        int n = word.length();
        if (word.equals("Kevin")) {
            char last = word.charAt(n - 1);
            System.out.println(last);
        }
        word = word.toUpperCase();
        System.out.println(word);
        System.out.println(word.substring(0, 3));
    }
}

Output: n, KEVIN, KEV on separate lines.

6. Eight paper checks

1. What is "Hi!".length()? What is its last index?

Check answer

3 and 2.

2. What does "Tennis".substring(1, 4) return?

Check answer

enn: indices 1, 2, 3.

3. What happens with "Hi".charAt(2)?

Check answer

IndexOutOfBoundsException: valid indices are 0 and 1.

4. What is "weather".indexOf("snow")?

Check answer

-1; a search miss is not an exception.

5. What does "Hello".substring(5) return?

Check answer

An empty String; end position 5 is allowed.

6. Does a method returning String necessarily print?

Check answer

No; store or print the returned value.

7. Why use equals for two user-entered names?

Check answer

It compares text content; == compares references.

8. What does "Score: " + 2 + 3 print? What about "Score: " + (2 + 3)?

Check answer

Score: 23 and Score: 5. Operations are evaluated left to right, with parentheses first.
