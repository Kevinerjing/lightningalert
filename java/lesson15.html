START HERE / HOW DECISIONS WORK

if vs else if vs else

A condition is a question Java can answer with true or false, such as mark >= 80. The statements inside { } run only when that branch is selected.

KeywordMeaningRule
if (condition)“Check this condition.”Starts a decision. It can stand alone.
else if (condition)“Otherwise, check this next condition.”Checked only if every earlier condition in this chain was false.
else“Otherwise, do this.”No condition. Runs only if all conditions in this chain were false.

1. Separate if statements: check each one

Each new, independent if starts another decision. More than one block can run.

int mark = 85;

if (mark >= 80) {
    System.out.println("80 or more");
}
if (mark >= 70) {
    System.out.println("70 or more");
}
if (mark >= 50) {
    System.out.println("50 or more");
}

Output:

80 or more
70 or more
50 or more

85 meets all three conditions, so all three messages print. A true condition does not stop the following independent if statements.

2. An if / else if / else chain: choose one branch

Use a chain when the program should select just one result, such as one grade level.

int mark = 85;

if (mark >= 80) {
    System.out.println("Level 4");
} else if (mark >= 70) {
    System.out.println("Level 3");
} else if (mark >= 60) {
    System.out.println("Level 2");
} else if (mark >= 50) {
    System.out.println("Level 1");
} else {
    System.out.println("Level 0");
}
System.out.println("Finished");

Output:

Level 4
Finished

The first condition is true, so Java prints Level 4 and skips the remaining branches in this chain. The program does not end: it continues after the chain and prints Finished.

If mark is…What Java checksSelected branch
8585 >= 80 is true; skip the rest.Level 4
7575 >= 80 is false; 75 >= 70 is true; skip the rest.Level 3
45All four conditions are false; use else.Level 0

Why does Level 3 only check mark >= 70? Java reaches that branch only after mark >= 80 was false. For an ordinary numeric mark, we already know it is below 80.

Order matters. If you put mark >= 50 first, a mark of 85 would match that branch and skip the higher levels. For this exercise, start with the highest cutoff.

3. else: the fallback, with no condition

int number = 6;

if (number % 2 == 0) {
    System.out.println("even");
} else {
    System.out.println("odd");
}

If the condition is true, print even. Otherwise, print odd. Write else {, not else (condition) {. Use else if when you need another condition.

You can have an if on its own, an if / else, or an if with several else if branches and an optional final else. A chain runs at most one branch; with a final else, it always selects one. Without else, it may select none.

4. Common mistake: which if does else belong to?

int mark = 85;

if (mark >= 80) {
    System.out.println("Level 4");
}
if (mark < 50) {
    System.out.println("Level 0");
} else {
    System.out.println("50 or more");
}

Output:

Level 4
50 or more

Here, else belongs to the second if. It does not mean “none of the if statements above were true.” The first if is a separate decision. Use braces consistently to make the grouping clear.

Remember: separate if statements can produce several results. An if / else if / else chain selects one result. Do not put a semicolon immediately after if (condition); put the opening brace there.

EXERCISE A

Marks

Read a mark as a double and print its level: 4 for 80 or more, 3 for 70–79.999..., 2 for 60–69.999..., 1 for 50–59.999..., and 0 below 50.

Sample input
67.5
Result
Level 2
Show solution — Marks

Check the highest level first. In an else-if chain, only the first matching branch runs.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        double mark = input.nextDouble();

        if (mark >= 80) {
            System.out.println("Level 4");
        } else if (mark >= 70) {
            System.out.println("Level 3");
        } else if (mark >= 60) {
            System.out.println("Level 2");
        } else if (mark >= 50) {
            System.out.println("Level 1");
        } else {
            System.out.println("Level 0");
        }
    }
}

EXERCISE B

Parity

Read an integer and print even or odd.

Sample input
6
Result
even
Show solution — Parity

The % operator gives the remainder. A remainder of zero when dividing by 2 means the number is even. This also works for zero and negative integers.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int number = input.nextInt();

        if (number % 2 == 0) {
            System.out.println("even");
        } else {
            System.out.println("odd");
        }
    }
}

EXERCISE C

Lottery

Read a five-digit lottery ticket number. 34567 wins $1,000,000. Other five-digit numbers lose; numbers outside 10000–99999 are invalid.

Sample input
34567
Result
You have won $1,000,000
Show solution — Lottery

Check the range before checking the winning number. || means OR. This beginner version assumes integer input: text and decimals are not handled by nextInt().

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter a five-digit lottery ticket number:");
        int number = input.nextInt();

        if (number < 10000 || number > 99999) {
            System.out.println("Your number is invalid");
        } else if (number == 34567) {
            System.out.println("You have won $1,000,000");
        } else {
            System.out.println("Better luck next time!");
        }
    }
}

EXERCISE D

Larger Number

Read two integers. Use if-statements to display the larger number, or say that they are equal.

Sample input
5 2
Result
5 is larger than 2
Show solution — Larger Number

Check whether the first number is larger, then whether the second is larger. If neither condition is true, they are equal.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num1 = input.nextInt();
        int num2 = input.nextInt();

        if (num1 > num2) {
            System.out.println(num1 + " is larger than " + num2);
        } else if (num2 > num1) {
            System.out.println(num2 + " is larger than " + num1);
        } else {
            System.out.println("The numbers are equal");
        }
    }
}

EXERCISE E

Winner

Introduce your game and read three integers. If addition, subtraction, multiplication or division of the first two produces the third, show one winning combination. Check both orders for subtraction and division. Never divide by zero.

Sample input
2 16 8
Result
16 / 2 = 8
CONGRATULATIONS - YOU WON!!!
Show solution — Winner

Use else if to show only one winning combination. For division, first check that the divisor is not zero, then that the remainder is zero, then that the quotient matches. && stops checking as soon as a condition is false, so the order protects against division by zero.

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Welcome to my fancy new game!");
        System.out.println("Enter any three integers:");
        int num1 = input.nextInt();
        int num2 = input.nextInt();
        int num3 = input.nextInt();

        if (num1 + num2 == num3) {
            System.out.println(num1 + " + " + num2 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else if (num1 - num2 == num3) {
            System.out.println(num1 + " - " + num2 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else if (num2 - num1 == num3) {
            System.out.println(num2 + " - " + num1 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else if (num1 * num2 == num3) {
            System.out.println(num1 + " * " + num2 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else if (num2 != 0 && num1 % num2 == 0 && num1 / num2 == num3) {
            System.out.println(num1 + " / " + num2 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else if (num1 != 0 && num2 % num1 == 0 && num2 / num1 == num3) {
            System.out.println(num2 + " / " + num1 + " = " + num3);
            System.out.println("CONGRATULATIONS - YOU WON!!!");
        } else {
            System.out.println("Sorry, better luck next time.");
        }
    }
}
