Understand %: what is left over?

Kevin: imagine sharing 17 counters into groups of 5. You can make 3 full groups, with 2 counters left. In Java, 17 / 5 gives the integer quotient, 3; 17 % 5 gives the remainder, 2. Here both operands are integers.

Say it aloud: “17 divided by 5 leaves 2.” The % symbol here is the remainder operator, often called mod. It does not mean percent.

A three-step mental method

  1. Find the largest multiple of 5 that does not exceed 17: 15.
  2. Subtract it: 17 − 15 = 2.
  3. Check: 17 = 5 × 3 + 2, and the remainder is smaller than 5.

For a nonnegative integer n and a positive divisor d, n % d is between 0 and d − 1. You do not have to perform long division.

  • Exact division: 20 % 5 is 0. Nothing is left over.
  • Smaller than the divisor: 3 % 5 is 3. No full group can be made.
  • Same number: 5 % 5 is 0, not 5.
  • Zero items: 0 % 5 is 0. But integer 5 % 0 causes an ArithmeticException: the divisor cannot be zero.

Turn words into a condition

  • “n is divisible by d”: n % d == 0, with d nonzero.
  • “n is even”: n % 2 == 0.
  • “n is odd”: n % 2 != 0.
  • “The last digit of a nonnegative integer n”: n % 10.
  • “Remove its last digit”: integer n / 10. For 247, % 10 gives 7; / 10 gives 24.

Separate calculation from decision: 14 % 4 is the number 2. 14 % 4 == 0 is false. The % calculates; == compares; an if decides what to do.

One Java detail: negative numbers

Java integer division truncates toward zero. -7 / 3 is -2 and -7 % 3 is -1, because -7 = 3 × (-2) + (-1). A nonzero remainder has the sign of the dividend (the left operand). This is why n % 2 != 0 also recognizes negative odd numbers, whereas n % 2 == 1 misses them. Practise positive numbers first.

Quick quiz · 1.3

Java Lab practice: these are extra revision questions, not CodeChef questions. Answer on paper before opening each explanation.

1. Quotient or remainder?

Find both 23 / 5 and 23 % 5.

Show answer and explanation

4 and 3. Check: 23 = 5 × 4 + 3.

2. Three small checks

Find 4 % 9, 9 % 9 and 0 % 9.

Show answer and explanation

4, 0, 0. Respectively: no full group; one exact group; no items left.

3. Choose one answer

What is 29 % 6? A: 4; B: 5; C: 6; D: 0.

Show answer and explanation

B: 5. The largest multiple at most 29 is 24, and 29 − 24 = 5. The answer 4 is the quotient.

4. Does it divide exactly?

Is 18 % 4 == 0 true or false? Give the remainder.

Show answer and explanation

False. 18 % 4 is 2, so 18 is not divisible by 4.

5. Split the digits

For int n = 386;, find n % 10 and n / 10.

Show answer and explanation

6 and 38. Remainder extracts the last digit; integer division removes it.

6. Spot the impossible remainder

A student says n % 5 equals 5 for a positive integer n. Could that happen?

Show answer and explanation

No. The possible remainders are 0, 1, 2, 3, 4. Five leftovers would make another full group.

7. Find the runtime error

Which causes an error with integer operands: 0 % 8 or 8 % 0?

Show answer and explanation

8 % 0 causes ArithmeticException. The divisor is zero. 0 % 8 is valid and equals 0.

8. Optional negative-number check

Find -9 % 2. Would -9 % 2 == 1 detect that -9 is odd?

Show answer and explanation

The remainder is -1. Comparing with 1 gives false; use -9 % 2 != 0, which is true.
