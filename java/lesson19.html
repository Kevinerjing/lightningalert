Switch Statements

Match one value to a case. Plan the choices first, then write the syntax.

Plan the choices

Kevin: write a small lookup table in words first. What value are you checking? What should each exact value do? What should happen if nothing matches?

Use switch for a menu option, a period number or a letter grade. Use if for ranges, inequalities or combinations of unrelated conditions.

This lesson follows your teacher’s arrow case syntax. Use Java 14 or later (Java 17 works). The older colon syntax is included for reading and debugging.

Classroom example

char block = 'C';
switch (block) {
    case 'A' -> System.out.println("Day 1 at 8:40am");
    case 'B' -> System.out.println("Day 1 at 10:05am");
    case 'C' -> System.out.println("Day 1 at 12:10pm");
    case 'D' -> System.out.println("Day 1 at 1:35pm");
    default -> System.out.println("ERROR");
}

Output: Day 1 at 12:10pm. These times follow the Class Code file; some slides use different example times.

  1. Evaluate block.
  2. Find the matching case.
  3. Run that arrow case and continue after the switch.

default handles an unmatched value. It is not an exception handler. Arrow cases do not require break.

Show complete beginner solution

public class Main {
    public static void main(String[] args) {

        char block = 'C';
        switch (block) {
            case 'A' -> System.out.println("Day 1 at 8:40am");
            case 'B' -> System.out.println("Day 1 at 10:05am");
            case 'C' -> System.out.println("Day 1 at 12:10pm");
            case 'D' -> System.out.println("Day 1 at 1:35pm");
            default -> System.out.println("ERROR");
        }
    }
}

Syntax to recognize

  • switch (value): the value being matched.
  • case 'A' ->: one character uses single quotes.
  • case "a", "A" ->: strings use double quotes; comma-separated labels share an action.
  • Use braces after the arrow for more than one statement.
  • For these lessons, use int, char or String selectors. Do not use a boolean condition or a decimal as the selector.
switch (grade) {
    case "a", "A" -> {
        System.out.println("Hello");
        System.out.println("Your percent mark is 80-100");
    }
    case "b", "B" -> System.out.println("Your percent mark is 70-79");
    default -> System.out.println("Invalid entry");
}

With String cases, switch compares string contents. In an if, use grade.equals("A") to compare contents.

Arrow versus colon

switch (choice) {
    case 1:
        System.out.println("One");
        break;
    case 2:
        System.out.println("Two");
        break;
    default:
        System.out.println("Other");
}

Colon cases can continue into following cases until a break or the end. Do not mix colon and arrow labels within the same switch. A break exits the nearest switch or loop; a break inside a switch nested in a loop does not exit that outer loop.

Six paper checks

1. Match a case

In the block example, change C to D. What prints?

Check answer and reasoning

Day 1 at 1:35pm. Only the matching arrow case runs.

2. Unmatched value

What prints for the lowercase character c?

Check answer and reasoning

ERROR. Character matching is case-sensitive and only uppercase C is listed.

3. Shared cases

String grade = "a";
switch (grade) {
    case "a", "A" -> {
        System.out.println("Hello");
        System.out.println("80-100");
    }
    default -> System.out.println("Invalid");
}
Check answer and reasoning

Hello, then 80-100 on the next line. Both labels lead to the same block.

4. Trace old syntax

int choice = 1;
switch (choice) {
    case 1: System.out.print("A");
    case 2: System.out.print("B"); break;
    default: System.out.print("C");
}
Check answer and reasoning

AB. There is no break after A, so execution falls through to B. With arrow cases, that fall-through does not occur.

5. Choose the structure

Would you use switch or if / else if for mark ≥ 80, mark ≥ 70, or lower?

Check answer and reasoning

Use if / else if for ranges. The classroom switch syntax matches exact values.

6. Repair syntax

switch (choice) {
    case 1 -> System.out.println("One");
    default System.out.println("Other");
}
Check answer and reasoning

Add the arrow: default -> System.out.println("Other");.

Write a small menu

Use a variable choice: 1 means Rock, 2 Paper, 3 Scissors, and anything else Invalid. Write a switch without looking above, then check.

Show complete beginner solution

public class Main {
    public static void main(String[] args) {

        int choice = 2;
        switch (choice) {
            case 1 -> System.out.println("Rock");
            case 2 -> System.out.println("Paper");
            case 3 -> System.out.println("Scissors");
            default -> System.out.println("Invalid");
        }
    }
}

Check choice = 1, 2, 3 and 0. The class random expression (int)(Math.random() * 3 + 1) produces 1, 2 or 3.

Reading the slides carefully

The card slide omits an arrow after default; use default -> value = -1;. A period example also has a missing closing quote. The reference programs here correct those syntax slips. For arrow cases, one matching rule runs; several independent conditions being true is an if-design question.
