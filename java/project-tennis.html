3. Explain how each concept is used

Variables, types and assignment

A variable gives a name to a stored value. A declaration introduces it; an assignment changes its value.

String playerName = "Kevin";
int totalMinutes = 0;
boolean running = true;
totalMinutes = totalMinutes + minutes;

String stores text; int stores whole numbers; double stores decimal numbers; boolean stores true or false. The final line is an assignment, not a new declaration.

Scanner, printing and concatenation

Scanner reads typed input. print displays a prompt without a new line; println ends the line. + joins text with values.

System.out.print("Successful serves: ");
int successful = readInt(input);
System.out.println("Welcome, " + playerName + "!");

The read helper calls nextInt() or nextDouble(). It retries a wrong number type. It does not check the allowed range; main does that separately.

Arithmetic and printf

Calculate before formatting. %.1f displays one decimal place; %n ends the line.

double rate = successful * 100.0 / attempts;
System.out.printf("Success rate: %.1f%%%n", rate);

12 * 100.0 / 20 = 60.0. The 100.0 makes decimal arithmetic. %% in a format string prints a literal %; it is different from the remainder operator.

If, else if, else and logical operators

A chained decision picks the first true branch. || means OR; && means AND.

if (rate >= 80) {
    System.out.println("Practice goal reached!");
} else if (rate >= 60) {
    System.out.println("Getting closer to the practice goal.");
} else {
    System.out.println("Keep practising your serve.");
}

For 85%, only the first message prints. A series of separate if statements could print more than one message. The 60% and 80% thresholds are chosen practice goals, not official tennis categories.

While loop: repeat until Exit

The menu repeats while running is true.

while (running) {
    // Print menu, read choice, handle the selected task.
}
// Exit case inside the switch:
running = false;

Choosing Exit changes running to false. The next while check ends the menu loop. while checks before its body; do-while checks after the body and therefore runs at least once.

For loop: repeat a known number of times

A counter controls exactly five iterations.

for (int day = 1; day <= 5; day++) {
    int minutes = readInt(input);
    totalMinutes = totalMinutes + minutes;
}

day starts at 1; day <= 5 is checked before each iteration; day++ adds 1 after each iteration. These shortened snippets show the loop idea; the complete code also prompts and checks ranges.

Switch and break

switch selects a menu action by an exact value. default handles an unlisted choice.

switch (choice) {
    case 1:
        // First feature
        break;
    case 2:
        // Second feature
        break;
    case 3:
        running = false;
        break;
    default:
        System.out.println("Choose 1, 2 or 3.");
}

A break in a case ends the switch and prevents fall-through. A break inside the for loop ends that loop instead. Neither automatically exits the entire program. This example uses traditional colon cases; arrow cases are another syntax from the lessons.

Try-catch: recover from a wrong input type

InputMismatchException occurs when nextInt receives a token such as hello or 2.5.

while (true) {
    try {
        return input.nextInt();
    } catch (InputMismatchException e) {
        input.nextLine();
        System.out.print("Please enter a whole number: ");
    }
}

The catch discards the bad input line; otherwise the same bad token would be read again. A successful read returns from the helper. Negative integers are still integers, so range checks belong in main. The weather readDouble helper uses the same pattern with nextDouble.

Methods: name a reusable task

Parameters receive inputs; return sends a result back. The caller decides whether to print it.

public static double calculateSuccessRate(int successful, int attempts) {
    return successful * 100.0 / attempts;
}
// In main, after checking attempts:
double rate = calculateSuccessRate(12, 20);

12 and 20 are arguments. successful and attempts are parameters. The return type is double; main stores 60.0 in rate. attempts is validated before the helper is called.

Remainder (%)

The % operator gives the remainder after division.

int hours = totalMinutes / 60;
int remainingMinutes = totalMinutes % 60;

For 185 minutes: 185 / 60 = 3 whole hours; 185 % 60 = 5 minutes left. For 25 minutes: 25 / 60 = 0; 25 % 60 = 25. The left number can be smaller.

4. Complete beginner reference program

Read this after planning the features. The complete program includes prompts and checks omitted from the short teaching snippets.

Show complete Java code
import java.util.InputMismatchException;
import java.util.Scanner;

public class TennisHelper {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        String playerName = "Kevin";
        boolean running = true;
        System.out.println("Welcome, " + playerName + "!");

        while (running) {
            System.out.println("\nTennis Training Helper");
            System.out.println("1. Check serve success rate");
            System.out.println("2. Total practice time for 5 days");
            System.out.println("3. Exit");
            System.out.print("Choose 1, 2 or 3: ");
            int choice = readInt(input);

            switch (choice) {
                case 1:
                    System.out.print("Total serve attempts (1-1000): ");
                    int attempts = readInt(input);
                    System.out.print("Successful serves: ");
                    int successful = readInt(input);
                    if (attempts < 1 || attempts > 1000
                            || successful < 0 || successful > attempts) {
                        System.out.println("Use 1-1000 attempts and successes from 0 to attempts.");
                    } else {
                        double rate = calculateSuccessRate(successful, attempts);
                        System.out.printf("Success rate: %.1f%%%n", rate);
                        // These are practice goals, not official tennis ratings.
                        if (rate >= 80) {
                            System.out.println("Practice goal reached!");
                        } else if (rate >= 60) {
                            System.out.println("Getting closer to the practice goal.");
                        } else {
                            System.out.println("Keep practising your serve.");
                        }
                    }
                    break;
                case 2:
                    int totalMinutes = 0;
                    boolean valid = true;
                    for (int day = 1; day <= 5; day++) {
                        System.out.print("Minutes for day " + day + " (0-1440): ");
                        int minutes = readInt(input);
                        if (minutes < 0 || minutes > 1440) {
                            System.out.println("Invalid minutes. Start again from the menu.");
                            valid = false;
                            break;
                        }
                        totalMinutes = totalMinutes + minutes;
                    }
                    if (valid) {
                        int hours = totalMinutes / 60;
                        int remainingMinutes = totalMinutes % 60;
                        System.out.println("Total: " + hours + " hours, "
                                + remainingMinutes + " minutes");
                        System.out.printf("Daily average: %.1f minutes%n", totalMinutes / 5.0);
                    }
                    break;
                case 3:
                    running = false;
                    break;
                default:
                    System.out.println("Choose 1, 2 or 3.");
            }
        }
        System.out.println("See you next practice!");
        input.close();
    }

    public static double calculateSuccessRate(int successful, int attempts) {
        return successful * 100.0 / attempts;
    }

    // Retry incorrect number types; range checks happen in main.
    public static int readInt(Scanner input) {
        while (true) {
            try {
                return input.nextInt();
            } catch (InputMismatchException e) {
                input.nextLine(); // Discard the bad input line before retrying.
                System.out.print("Please enter a whole number: ");
            }
        }
    }
}

Helpers are inside the class, alongside main. The input helpers are slightly more advanced because their Scanner parameter lets them read from the same input source.

6. Explain three kinds of errors

  • Syntax: remove the semicolon after a println statement. The compiler cannot compile it.
  • Runtime: calling nextInt directly with hello causes InputMismatchException if it is not caught.
  • Logic: the following compiles, but integer division can produce a wrong answer:
double rate = successful / attempts * 100;

For 12 and 20, 12 / 20 is integer division and gives 0. Use successful * 100.0 / attempts.

Range validation checks sensible values; try-catch handles an exception. They solve different problems.
