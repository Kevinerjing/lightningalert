How to use this review

Kevin: start with an example you can solve by hand. Write input → steps → output. Then translate one step at a time into Java. You do not need to remember the whole program at once.

Each exercise has a hidden plan and a separate Main.java. Input examples use ordinary console tokens; retry programs assume the user continues entering values. Exercises 2 and 3 have no input to validate.

Choose the skills you need most, as the worksheet allows. Questions 6–8 are challenges. The Part A/B/C grouping below is a revision format, not a confirmed exam paper.

Review % first if remainders are slowing you down. Match the structure: exact choices → switch; ranges → if; repetition → loop; invalid input → checks or try/catch.

1. Seconds to hours, minutes and seconds

Read a movie length in seconds. Reject invalid input and negative lengths. Print hours, minutes and seconds with singular/plural words.

Plan before coding
  1. Read a nonnegative integer.
  2. Take full hours using / 3600.
  3. The leftover seconds are total % 3600. Divide those by 60 for minutes; use % 60 for seconds.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int total = -1;
        while (total < 0) {
            System.out.println("Enter the movie length in seconds:");
            if (input.hasNextInt()) {
                total = input.nextInt();
                if (total < 0) {
                    System.out.println("Use zero or a positive integer.");
                }
            } else {
                System.out.println("Please enter an integer.");
                input.next();
            }
        }
        int hours = total / 3600;
        int remaining = total % 3600;
        int minutes = remaining / 60;
        int seconds = remaining % 60;
        System.out.print(hours);
        if (hours == 1) {
            System.out.print(" hour, ");
        } else {
            System.out.print(" hours, ");
        }
        System.out.print(minutes);
        if (minutes == 1) {
            System.out.print(" minute, ");
        } else {
            System.out.print(" minutes, ");
        }
        System.out.print(seconds);
        if (seconds == 1) {
            System.out.println(" second.");
        } else {
            System.out.println(" seconds.");
        }

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: hi then 3721 → reject hi, then 1 hour, 2 minutes, 1 second. 1 → 0 hours, 0 minutes, 1 second. 3600 → 1 hour, 0 minutes, 0 seconds. 0 → all zero.

For 3721: one hour uses 3600 seconds, leaving 121; two minutes use 120, leaving 1. The teacher solution’s comment says “1 minute” at the end; it should be “1 second.”

2. Divisible by 3 or 5

Print numbers from 5 through 100 that are divisible by 3 or 5.

Plan before coding
  1. Generate every candidate from 5 through 100.
  2. Check divisibility by 3 OR divisibility by 5.
  3. Print a candidate once if either condition is true.
Show complete beginner solution

public class Main {
    public static void main(String[] args) {

        for (int number = 5; number <= 100; number++) {
            if (number % 3 == 0 || number % 5 == 0) {
                System.out.print(number + ", ");
            }
        }
        System.out.println();
    }
}

Download Main.java — run each download separately.

Test it: Starts 5, 6, 9, 10, 12, 15; ends 96, 99, 100. There are 45 numbers; 15 appears once.

Use || (or), not && (and). Two independent if statements would print common multiples twice. The trailing comma follows the worksheet sample. No input is needed.

3. Growing descending pattern

Print 9, then 98, then 987, continuing to 987654321, one line each.

Plan before coding
  1. Start a running number at 0.
  2. Take digits 9 down to 1.
  3. Multiply the previous number by 10, add the new digit and print.
Show complete beginner solution

public class Main {
    public static void main(String[] args) {

        int number = 0;
        for (int digit = 9; digit >= 1; digit--) {
            number = number * 10 + digit;
            System.out.println(number);
        }
    }
}

Download Main.java — run each download separately.

Test it: Nine lines: 9, 98, 987, 9876, 98765, 987654, 9876543, 98765432, 987654321.

Trace: 9 × 10 + 8 = 98, then 98 × 10 + 7 = 987. All nine values fit in int. No input is needed.

4. Perfect square

Read an integer and decide whether it is a perfect square.

Plan before coding
  1. Negative integers cannot be squares of whole numbers. Zero is a perfect square.
  2. Try roots 0, 1, 2… until the square would exceed the input.
  3. Stop when a square equals the input.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter an integer:");
        while (!input.hasNextInt()) {
            System.out.println("Please enter an integer.");
            input.next(); // discard one invalid token
        }
        int number = input.nextInt();
        boolean isSquare = false;
        for (long root = 0; root * root <= number; root++) {
            if (root * root == number) {
                isSquare = true;
                break;
            }
        }
        if (isSquare) {
            System.out.println(number + " is a perfect square");
        } else {
            System.out.println(number + " is not a perfect square");
        }

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: 25 → yes; 26 → no; 0 → yes; -4 → no; hello then 16 → reject text, then yes.

long is used only for root so multiplication cannot overflow int for an int input. The posted solution starts at 1 and therefore misses 0; starting at 0 includes 0 × 0.

5. Classify a triangle

Read three integer side lengths. If a token is not an integer, print an exit message. Otherwise check validity and classify the triangle.

Plan before coding
  1. Read three integers; stop on invalid input.
  2. Require positive lengths and the sum of any two sides to exceed the third.
  3. Check all equal first, then any equal pair, then all different.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter three integer side lengths:");
        if (!input.hasNextInt()) {
            System.out.println("A value entered is not an integer. Exiting program.");
            input.close();
            return;
        }
        int a = input.nextInt();
        if (!input.hasNextInt()) {
            System.out.println("A value entered is not an integer. Exiting program.");
            input.close();
            return;
        }
        int b = input.nextInt();
        if (!input.hasNextInt()) {
            System.out.println("A value entered is not an integer. Exiting program.");
            input.close();
            return;
        }
        int c = input.nextInt();
        if (a <= 0 || b <= 0 || c <= 0) {
            System.out.println("Side lengths must be positive.");
        } else if ((long) a + b <= c || (long) a + c <= b || (long) b + c <= a) {
            System.out.println("These sides do not form a triangle.");
        } else if (a == b && b == c) {
            System.out.println("Equilateral");
        } else if (a == b || b == c || a == c) {
            System.out.println("Isosceles");
        } else {
            System.out.println("Scalene");
        }

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: 3 3 3 → Equilateral; 3 3 4 → Isosceles; 3 4 5 → Scalene; 1 2 3 → not a triangle; hi 30 60 → exit message.

return ends main after bad input; it is not a loop break. Casting to long before addition prevents overflow for large int sides. The posted answer checks positivity but omits the triangle inequality, so 1, 2, 3 would be misclassified.

6. Challenge: sum and product

Find two positive integers with a given sum and product, or report that none exist.

Plan before coding
  1. Read a positive sum and a positive product.
  2. Try the smaller number first = 1 through sum / 2.
  3. The other number must be sum − first; check their product.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int sum = 0;
        while (sum <= 0) {
            System.out.println("Enter a positive integer sum:");
            if (input.hasNextInt()) {
                sum = input.nextInt();
                if (sum <= 0) System.out.println("The sum must be positive.");
            } else {
                System.out.println("Please enter an integer.");
                input.next();
            }
        }
        int product = 0;
        while (product <= 0) {
            System.out.println("Enter a positive integer product:");
            if (input.hasNextInt()) {
                product = input.nextInt();
                if (product <= 0) System.out.println("The product must be positive.");
            } else {
                System.out.println("Please enter an integer.");
                input.next();
            }
        }
        boolean found = false;
        for (int first = 1; first <= sum / 2; first++) {
            int second = sum - first;
            if ((long) first * second == product) {
                System.out.println(first + " and " + second);
                found = true;
                break;
            }
        }
        if (!found) {
            System.out.println("No positive integer pair exists.");
        }

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: sum 7, product 10 → 2 and 5; 6, 9 → 3 and 3; 5, 7 → no pair; product 0 must be rejected.

The posted product-validation block checks add > 0 instead of multiply > 0. Check the value you just read. Use small practice inputs: this direct search can take many iterations. Optional signed extension: allow signed inputs and, for nonzero product p, test divisors from −|p| to |p|, skipping zero; pair each divisor with p / divisor and check the sum. Use long for the magnitude of an int. If p = 0, the pair is 0 and the requested sum.

7. Challenge: primes below a limit

Read an integer and print all prime numbers strictly smaller than it.

Plan before coding
  1. A prime is at least 2 and has no divisors other than 1 and itself.
  2. Try candidates from 2 up to, but not including, the limit.
  3. For each candidate, reset a flag and search for a divisor from 2 through candidate / 2. Stop at the first divisor.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter an integer limit:");
        while (!input.hasNextInt()) {
            System.out.println("Please enter an integer.");
            input.next(); // discard one invalid token
        }
        int limit = input.nextInt();
        for (int candidate = 2; candidate < limit; candidate++) {
            boolean isPrime = true;
            for (int divisor = 2; divisor <= candidate / 2; divisor++) {
                if (candidate % divisor == 0) {
                    isPrime = false;
                    break;
                }
            }
            if (isPrime) {
                System.out.print(candidate + " ");
            }
        }
        System.out.println();

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: 10 → 2 3 5 7; 3 → 2; 2 or any smaller limit → no primes; 13 is not included when the limit is 13.

For candidate 2, the inner loop runs zero times and isPrime stays true. Reset isPrime inside the outer loop. The posted solution starts at 1, which incorrectly prints 1 as prime. This beginner trial-divisor method is for small practice limits.

8. Challenge: sum of digits

Read an integer and print the sum of its decimal digits. This version also handles zero and negative int inputs.

Plan before coding
  1. Work on the magnitude so a minus sign is not treated as a digit.
  2. Read the last digit with % 10.
  3. Add it to the sum and remove it with / 10.
Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter an integer:");
        while (!input.hasNextInt()) {
            System.out.println("Please enter an integer.");
            input.next(); // discard one invalid token
        }
        int number = input.nextInt();
        long remaining = number;
        if (remaining < 0) {
            remaining = -remaining;
        }
        int sum = 0;
        while (remaining > 0) {
            int digit = (int) (remaining % 10);
            sum = sum + digit;
            remaining = remaining / 10;
        }
        System.out.println(sum);

        input.close();
    }
}

Download Main.java — run each download separately.

Test it: 305 → 8; 0 → 0; -247 → 13; -2147483648 → 47; hello then 123 → reject text, then 6.

Convert to long before negating, because the magnitude of the smallest int does not fit in int. For positive-only class work, an int copy and the same % 10, / 10 loop are enough. The posted while (num2 > 0) returns 0 for negative inputs without processing their digits.

Part A: explain

A1. Declaration and initialization

Explain int score; versus int score = 0;.

Check answer and reasoning

The first declares a local variable. The second declares it and gives it an initial value. A local variable must have a value before it is read.

A2. Operators

Explain !=, += and %. What are the three parts of a for header?

Check answer and reasoning

!= means not equal; x += 3 adds 3 to x; % gives a remainder. A for header contains initialization, condition and update.

A3. Eight primitive types

Name Java’s eight primitive types. Is String one?

Check answer and reasoning

byte, short, int, long, float, double, char, boolean. String is a reference type.

A4. Control flow

How do while, do-while and a nested if work?

Check answer and reasoning

while checks before the body, so it can run zero times. do-while checks afterward, so its body runs at least once. A nested if is reached only when execution enters its enclosing branch.

A5. Errors

Give examples of a compile-time error, a runtime exception and a logic error.

Check answer and reasoning

Missing quote: compile-time error. Integer division by zero: runtime exception. Using && instead of || when the task says “or”: logic error. The review slides ask for two categories but do not identify which two; follow your teacher’s terminology while understanding these distinctions.

Part B: trace and debug

B1. Printed text

System.out.print("Hello 15 +5" + (10 + 5) + "5");
Check answer and reasoning

Exactly Hello 15 +5155, with no newline. Text inside quotes stays text; the parentheses calculate 15; the last "5" is appended.

B2. Arithmetic

Find 3 * 9 * (3 + (9 * 3 / 3)) and 2 % 2 + 2 * 2 - 2 / 2.

Check answer and reasoning

324 and 3. First: 9 × 3 / 3 = 9; 3 + 9 = 12; 27 × 12 = 324. Second: 0 + 4 − 1 = 3.

B3. Missing values on the slide

The slide declares int x; and int xLimit;, then uses while (x <= xLimit) without assigning either. Can you predict an output?

Check answer and reasoning

As shown, it does not compile: the local variables are uninitialized. For extra practice, set x = 1 and xLimit = 3. Because x++ is before printing, the body prints values 2, 3, 4; final x is 4.

B4. Repair the temperature example

int temp = 20;
if (temp = 35) {
    System.out.println("Nice");
}
Check answer and reasoning

Use temp == 35. Assignment to an int is not a boolean condition. The slide also capitalizes Public/Class and uses curly quotation marks: Java requires lowercase public/class and straight quotes. With those repaired and the full slide’s branches, temp = 20 prints Not bad.

B5. Repair the grade example

The slide has a mark of 80 and a middle condition mark < 80 && mark <= 70. What needs attention?

Check answer and reasoning

As printed, syntax problems (Public/Class, curly quotes and a missing closing brace before else if) prevent compilation. After repairing them, mark 80 prints A - Well done! For the intended 70–79 middle range, use mark >= 70 after the first mark >= 80 branch. Test 69, 70, 79 and 80.

C2. Print 1 to n using while

Require a positive integer n and print commas between the numbers, with no trailing comma.

Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int n = 0;
        while (n <= 0) {
            System.out.println("Enter a positive integer:");
            if (input.hasNextInt()) {
                n = input.nextInt();
                if (n <= 0) System.out.println("Incorrect input: use a positive integer.");
            } else {
                System.out.println("Please enter an integer.");
                input.next();
            }
        }
        int number = 1;
        while (number <= n) {
            if (number > 1) System.out.print(", ");
            System.out.print(number);
            if (number == n) break;
            number++;
        }
        System.out.println();

        input.close();
    }
}

Download Main.java — run each download separately.

Check n = 1 → 1; n = 3 → 1, 2, 3. Use small n for manageable output. The break avoids updating past the largest int.

C3. Sum ten doubles

Read ten valid decimal numbers and print their sum. Invalid tokens do not count toward the ten.

Show complete beginner solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        double sum = 0;
        int count = 0;
        while (count < 10) {
            System.out.println("Enter a number:");
            if (input.hasNextDouble()) {
                double number = input.nextDouble();
                if (Double.isFinite(number)) {
                    sum = sum + number;
                    count++;
                } else {
                    System.out.println("Use a finite number.");
                }
            } else {
                System.out.println("Please enter a number.");
                input.next();
            }
        }
        System.out.println(sum);

        input.close();
    }
}

Download Main.java — run each download separately.

The slide’s ten values total 43.0, not the printed 42.5: 2.5, 3.0, 1.25, 4.75, 10.25, 3.5, 2.5, 5.25, 7.5, 2.5. Double.isFinite is an extra guard against NaN and Infinity; the core classroom idea is to update the sum and count only after a valid read. Extremely large finite values can still overflow a double sum; use ordinary classroom values.

Before handing in

  • Read the exact endpoints: inclusive or strictly smaller?
  • Try one normal case, one boundary and one invalid input.
  • Use / for an integer quotient and % for a remainder.
  • Initialize sums to 0, products to 1, and reset per-candidate flags inside the loop.
  • Check == versus =, && versus ||, braces, quotes and loop updates.
  • Explain why the loop covers all candidates and eventually stops.

For marking criteria, show correct data types and operators (A1), input/processing/output and control structures (A2), and clear names, indentation and useful comments (A4).
