1. Think about the repetition before the syntax

Kevin: first describe what happens once. Then decide where to start, when to stop and what changes. You can write these four ideas as comments before remembering the Java punctuation.

Example: print the numbers 1 through 4.

  1. One action: print the current number.
  2. Start: 1.
  3. Keep going: while the number is at most 4.
  4. Change: add 1 after printing.
for (int i = 1; i <= 4; i++) {
    System.out.println(i);
}

Read it as: “Start at 1; while i is at most 4, print it, then add 1.” A for loop is convenient when the repetitions are controlled by a counter. A while loop is often clearer when waiting for valid input. Both can express the same basic repetition; for is not inherently more powerful.

2. Start once → check → body → update → check again

for (initialization; condition; update) {
    // repeated work
}

This is a syntax template: replace the three words with Java statements/expressions. The header contains two semicolons. There is no extra semicolon between the closing parenthesis and the opening brace.

i before checki <= 4Body printsUpdate
1true1i becomes 2
2true2i becomes 3
3true3i becomes 4
4true4i becomes 5
5falseNothingNo update; exit

Four prints, five condition checks. Initialization happens once. The update happens after each completed body execution, not before the first print.

Scope: with for (int i = ...), i only exists inside that loop. It reaches 5 for the last check, but you cannot print i after the loop. Declare it before the loop if you need it afterward.

int i;
for (i = 1; i <= 4; i++) {
    System.out.println(i);
}
System.out.println(i); // 5
Compare with the while version
int i = 1;
while (i <= 4) {
    System.out.println(i);
    i++;
}

3. Common patterns and stopping mistakes

HeaderValues used by the body
for (int i = 0; i < 5; i++)0, 1, 2, 3, 4: five runs
for (int i = 1; i <= 5; i++)1, 2, 3, 4, 5: five runs
for (int i = 0; i < 100; i += 2)0, 2, …, 98: 50 runs
for (int i = 99; i >= 0; i--)99 down to 0: 100 runs
for (int i = 5; i < 4; i++)Zero runs: the first check is false

Trace the first value, last valid value and first failing value. Do not assume that < and <= give the same number of runs.

Wrong direction: starting j at 0 with j < 100 but using j-- moves away from the intended exit. Java int eventually overflows, so do not call this literally endless; it is still a broken counting loop. Use the direction that moves toward your stopping value.

Keep the counter update in the header. Changing it again inside the body usually skips values. Short counters such as i and j are normal; descriptive names such as row and candidate can make a solution clearer.

for (int j = 99; j >= 0; j--) {
    System.out.print(j + " ");
    if (j == 90) {
        break;
    }
}

This classroom pattern prints 99 down to 90, including 90: ten numbers. break exits immediately, before the next update. It exits the nearest loop, not the whole program.

4. Nested loops: finish the inner loop for each outer value

for (int row = 1; row <= 3; row++) {
    for (int column = 1; column <= row; column++) {
        System.out.print(column + " ");
    }
    System.out.println();
}
1
1 2

The outer loop chooses the row. Each new row starts a fresh inner loop at column = 1. The newline belongs after the inner loop, inside the outer loop.

The triangle prints 1 + 2 + 3 = 6 numbers. In the classroom example where both i and j go from 1 to 9, println(i * j) runs 9 × 9 = 81 times. That prints 81 entries, not 81 distinct products.

The teacher’s example uses int and asks for a positive integer. The reference below limits input to 1–12 because 13! exceeds the int range. Mathematically 0! = 1, but this example follows the positive-input requirement.

Show complete factorial example
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter an integer from 1 to 12:");
        if (input.hasNextInt()) {
            int number = input.nextInt();
            if (number >= 1 && number <= 12) {
                int factorial = 1;
                for (int i = 1; i <= number; i++) {
                    factorial = factorial * i;
                }
                System.out.println(number + "! = " + factorial);
            } else {
                System.out.println("Enter a value from 1 to 12.");
            }
        } else {
            System.out.println("Invalid input.");
        }

        input.close();
    }
}

3. Find every factor

Read a positive integer and display its positive factors in increasing order.

Hint: plan before coding
  1. Validate the input.
  2. Try each candidate from 1 through the number.
  3. Print a candidate when the remainder is zero.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num <= 0) {
            System.out.println("Enter a positive integer:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        for (int candidate = 1; candidate <= num; candidate++) {
            if (num % candidate == 0) {
                System.out.print(candidate + " ");
            }
            if (candidate == num) {
                break;
            }
        }
        System.out.println();

        input.close();
    }
}

The final break stops before the counter could overflow at the largest int. This simple trial method is intended for small practice inputs; very large numbers take many iterations.

4. Is the number a palindrome?

Read a positive integer, reverse its digits using a for loop, and compare with the original.

Hint: plan before coding
  1. Keep the original number unchanged.
  2. Take the last digit with % 10.
  3. Append it: reversed = reversed * 10 + digit.
  4. Remove the digit with / 10. Repeat until no digits remain.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num <= 0) {
            System.out.println("Enter a positive integer:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        long reversed = 0;
        for (int remaining = num; remaining > 0; remaining /= 10) {
            int digit = remaining % 10;
            reversed = reversed * 10 + digit;
        }
        if (reversed == num) {
            System.out.println(num + " is a palindrome");
        } else {
            System.out.println(num + " is not a palindrome");
        }

        input.close();
    }
}

long is an integer type with a wider range than int. Only reversed needs it, because reversing a valid int can produce a value too large for int. The loop removes digits instead of multiplying a place-value counter, so that counter cannot overflow.

The digit-counting version starts length at 1. Its condition must be originalNum >= 10, not >= 9. For 9, the printed condition counts an extra digit and reverses it to 90. The same issue affects numbers whose leading digit is 9.

5. Between two integers

Read two integers and print both endpoints and every integer between them. The worksheet sample uses 6 and 13. This version also accepts descending input.

Hint: plan before coding
  1. Read and validate two integers (spaces or newlines are accepted).
  2. If the first is smaller, count up. Otherwise count down.
  3. Stop immediately after printing the second endpoint.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter two integers:");
        while (!input.hasNextInt()) {
            input.next();
            System.out.println("Please enter an integer:");
        }
        int first = input.nextInt();
        while (!input.hasNextInt()) {
            input.next();
            System.out.println("Please enter the second integer:");
        }
        int last = input.nextInt();
        if (first <= last) {
            for (int i = first; i <= last; i++) {
                System.out.print(i + " ");
                if (i == last) {
                    break;
                }
            }
        } else {
            for (int i = first; i >= last; i--) {
                System.out.print(i + " ");
                if (i == last) {
                    break;
                }
            }
        }
        System.out.println();

        input.close();
    }
}

Here next() discards only one invalid token, so the two valid integers may be on the same line. The break also prevents an extra update past the int limits. Use nearby endpoints for manageable output.

6. A growing number triangle

Print nine rows: row 1 contains 1, row 2 contains 1 2, and so on through row 9.

Hint: plan before coding
  1. Use the outer counter for rows 1–9.
  2. For each row, count from 1 to that row number.
  3. Print one newline after the inner loop finishes.
Show reference solution
public class Main {
    public static void main(String[] args) {
        for (int row = 1; row <= 9; row++) {
            for (int number = 1; number <= row; number++) {
                System.out.print(number + " ");
            }
            System.out.println();
        }
    }
}

The inner loop starts again at 1 on every row. Putting println inside the inner loop would place every number on its own line.

Indices start at 0. Invalid numeric text passed to parseInt/parseDouble throws NumberFormatException. The classroom examples use known valid strings.

Trace a string loop
String text = "Cat";
for (int i = 0; i <= text.length(); i++) {
    System.out.println(text.substring(i));
}

Prints Cat, at, t, then an empty line. substring(length) is valid and returns an empty string. Going beyond length would cause an error.

Reading a full line after a number
int number = input.nextInt(); // assume valid integer input
input.nextLine(); // consume the remainder of this line
String text = input.nextLine(); // read the next full line

nextInt leaves the remainder of the line, including its newline; it does not leave a “null character.” Use one Scanner on System.in. An extra nextLine consumes that remainder before you ask for the next full line.

break versus System.exit

break; exits the nearest enclosing loop. System.exit(0); terminates the running program normally; a nonzero status such as System.exit(1); conventionally signals a failure. Do not substitute System.exit when you only want to stop one loop.
