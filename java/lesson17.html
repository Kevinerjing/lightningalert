1. Initialize → check → body → update → check again

int currentNum = 0;
while (currentNum <= 9) {
    System.out.print(currentNum + " ");
    currentNum++;
}
System.out.println("Final: " + currentNum);

Numbers printed: 0 through 9. Final value: 10. The counter changes after each print; the final failed check also matters.

currentNum++ adds 1. total += number means total = total + number. A loop needs something that can eventually make its condition false, or a reachable break.

if vs while: if checks once for that decision. while rechecks after each completed iteration.

2. while, do-while and break

StructureCondition checkedMinimum runs
whileBefore the body0
do-whileAfter the body1
int i = 5;
while (i < 3) {
    System.out.println(i);
    i++;
}
// Prints nothing. i is still 5.

do {
    System.out.println(i);
    i++;
} while (i < 3);
// Prints 5 once. i is now 6.

No semicolon immediately after a normal while (condition). A do { ... } while (condition); does need its final semicolon.

int i = 1;
while (i <= 5) {
    if (i == 3) {
        break;
    }
    System.out.print(i + " ");
    i++;
}
System.out.println("Done");

Output: 1 2 Done. break exits the nearest enclosing loop immediately; it does not end the whole program. Here i remains 3.

3. Keep asking until the input is valid

The outer loop checks the range; the inner loop rejects non-integer input. Starting at 0 deliberately makes the 1–10 range invalid so the first prompt appears.

int num = 0;
while (num < 1 || num > 10) {
    System.out.println("Enter an integer from 1 to 10:");
    while (!input.hasNextInt()) {
        input.nextLine();
        System.out.println("Please enter an integer:");
    }
    num = input.nextInt();
    input.nextLine();
}

! means NOT. num < 1 || num > 10 means below the minimum OR above the maximum. Using AND here would never be true.

MethodWhat it does
hasNextInt()Checks the next token; consumes nothing
nextInt()Consumes the integer token; leaves the remainder of the line
nextLine()Consumes the remainder of the current line, including the line separator

Inside the invalid-input loop, nextLine discards the bad line so the same bad token is not checked forever. After a successful nextInt, it consumes any remaining text and the newline. It is not always “clearing a bad value.” This line-based pattern intentionally discards extra tokens on that line; enter one answer per line.

When switching from nextInt to reading a full line of text, consume the leftover newline before the intended nextLine read.

4. Replay, login and totals

Replay with a boolean

boolean playAgain = true;
while (playAgain) {
    System.out.println("Game round");
    System.out.println("Play again? Enter true or false:");
    while (!input.hasNextBoolean()) {
        input.nextLine();
        System.out.println("Enter true or false:");
    }
    playAgain = input.nextBoolean();
    input.nextLine();
}

The classroom example uses true/false, not yes/no. Updating playAgain gives the loop a way to finish.

10a. Count sevens

Use % 10 and integer division by 10 to count digits equal to 7.

Hint: plan before coding
  1. Take the last digit.
  2. Count it if it is 7.
  3. Remove it; repeat until no digits remain.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        int sevens = 0;
        while (num >= 1) {
            int digit = num % 10;
            if (digit == 7) {
                sevens++;
            }
            num = num / 10;
        }
        System.out.println("Sevens: " + sevens);

        input.close();
    }
}

10b. Odd and even digits

Count odd digits and even digits in a positive integer.

Hint: plan before coding
  1. Extract one digit with % 10.
  2. Use digit % 2 to classify it.
  3. Remove the digit.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        int odd = 0;
        int even = 0;
        while (num >= 1) {
            int digit = num % 10;
            if (digit % 2 == 0) {
                even++;
            } else {
                odd++;
            }
            num /= 10;
        }
        System.out.println("Odd: " + odd);
        System.out.println("Even: " + even);

        input.close();
    }
}

10c. Sum of digits

Find the sum of the digits of a positive integer.

Hint: plan before coding
  1. Initialize sum at 0.
  2. Extract the last digit and add it.
  3. Remove the last digit.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        int sum = 0;
        while (num >= 1) {
            int digit = num % 10;
            sum += digit;
            num /= 10;
        }
        System.out.println("Digit sum: " + sum);

        input.close();
    }
}

10d. Three consecutive ascending digits

Determine whether the number contains three adjacent digits that increase by 1 from left to right.

Interpretation: consecutive integers means a step of exactly 1, such as 123 or 678; 135 and 890 do not qualify. % 10 extracts right to left, so take care to test the original left-to-right order.

Hint: plan before coding
  1. Inspect the last three digits if at least three remain.
  2. Check left + 1 = middle and middle + 1 = right.
  3. Remove one digit to slide the window; stop on a match.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        boolean found = false;
        while (num >= 100) {
            int right = num % 10;
            int middle = (num / 10) % 10;
            int left = (num / 100) % 10;
            if (left + 1 == middle && middle + 1 == right) {
                found = true;
                break;
            }
            num /= 10;
        }
        System.out.println(found);

        input.close();
    }
}
