1. Initialize → check → body → update → check again

int currentNum = 0;
while (currentNum <= 9) {
    System.out.print(currentNum + " ");
    currentNum++;
}
System.out.println("Final: " + currentNum);

Numbers printed: 0 through 9. Final value: 10. The counter changes after each print; the final failed check also matters.

9true910
10falseNothing; exit10

currentNum++ adds 1. total += number means total = total + number. A loop needs something that can eventually make its condition false, or a reachable break.

if vs while: if checks once for that decision. while rechecks after each completed iteration.

2. while, do-while and break

StructureCondition checkedMinimum runs
whileBefore the body0
do-whileAfter the body1
int i = 5;
while (i < 3) {
    System.out.println(i);
    i++;
}
// Prints nothing. i is still 5.

do {
    System.out.println(i);
    i++;
} while (i < 3);
// Prints 5 once. i is now 6.

No semicolon immediately after a normal while (condition). A do { ... } while (condition); does need its final semicolon.

int i = 1;
while (i <= 5) {
    if (i == 3) {
        break;
    }
    System.out.print(i + " ");
    i++;
}
System.out.println("Done");

Output: 1 2 Done. break exits the nearest enclosing loop immediately; it does not end the whole program. Here i remains 3.

3. Keep asking until the input is valid

The outer loop checks the range; the inner loop rejects non-integer input. Starting at 0 deliberately makes the 1–10 range invalid so the first prompt appears.

int num = 0;
while (num < 1 || num > 10) {
    System.out.println("Enter an integer from 1 to 10:");
    while (!input.hasNextInt()) {
        input.nextLine();
        System.out.println("Please enter an integer:");
    }
    num = input.nextInt();
    input.nextLine();
}

! means NOT. num < 1 || num > 10 means below the minimum OR above the maximum. Using AND here would never be true.

MethodWhat it does
hasNextInt()Checks the next token; consumes nothing
nextInt()Consumes the integer token; leaves the remainder of the line
nextLine()Consumes the remainder of the current line, including the line separator

Inside the invalid-input loop, nextLine discards the bad line so the same bad token is not checked forever. After a successful nextInt, it consumes any remaining text and the newline. It is not always “clearing a bad value.” This line-based pattern intentionally discards extra tokens on that line; enter one answer per line.

When switching from nextInt to reading a full line of text, consume the leftover newline before the intended nextLine read.

4. Replay, login and totals

Replay with a boolean

boolean playAgain = true;
while (playAgain) {
    System.out.println("Game round");
    System.out.println("Play again? Enter true or false:");
    while (!input.hasNextBoolean()) {
        input.nextLine();
        System.out.println("Enter true or false:");
    }
    playAgain = input.nextBoolean();
    input.nextLine();
}

The classroom example uses true/false, not yes/no. Updating playAgain gives the loop a way to finish.

Login condition from the slides

while (username.compareTo("student1") != 0
        || password.compareTo("star") != 0) {
    System.out.println("Incorrect!");
    username = input.nextLine();
    password = input.nextLine();
}

Assume username and password were already read, as in the slides. compareTo returns 0 when the strings match. Repeat if either is wrong; stop only when both match. Do not use == to compare String contents.

Read code exactly as written

In the slides’ total example, the number is read and added inside the body before the next condition check. A newly entered negative number therefore gets added once, and a total of exactly 1000 still allows another iteration because the condition is ≤ 1000. A stopping value is called a sentinel; if you want to exclude it, check it before adding. Follow the actual statements when tracing, not just the comment.

The supplementary notes also contain an old drawing call and a mismatched comment. For console practice, use System.out.println; the shown do-while with i starting at 1 and condition i < 10 prints nine times and ends at i = 10.

5. Predict before revealing

A. Start i at 1, print it while i < 5, then increment. What prints and what is the final i?

Answer A

Prints 1, 2, 3, 4. Final i = 5. Replacing < with ≤ prints 1 through 5 and ends at 6.

B. A while condition is false at the start. How many times does the body run? What about do-while?

Answer B

while: zero. do-while: at least once; it checks after the first body execution.

C. A loop checks hasNextInt repeatedly after the user enters hello, but never consumes anything. Why does it get stuck?

Answer C

It keeps seeing the same invalid token. Consume invalid input, for example with nextLine, before checking again.

3. 24-hour time to am/pm

Keep asking for an integer hour from 0 to 23, then display 12-hour time.

Based on the teacher’s posted exercise 3 solution. The successful nextLine consumes the rest of the line; it is not removing a bad integer.

Hint: plan before coding
  1. Reject non-integers.
  2. Reject integers outside 0–23.
  3. Handle midnight, morning, noon, then afternoon/evening.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int time = -1;
        while (time < 0 || time > 23) {
            System.out.println("Enter an integer from 0 to 23:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            time = input.nextInt();
            input.nextLine();
        }
        if (time == 0) {
            System.out.println("It is 12 am.");
        } else if (time < 12) {
            System.out.println("It is " + time + " am.");
        } else if (time == 12) {
            System.out.println("It is 12 pm.");
        } else {
            System.out.println("It is " + (time - 12) + " pm.");
        }

        input.close();
    }
}

Read a positive integer n and print 1 through n on one line, separated by commas.

import java.util.Scanner;

5. Sum ten doubles

Read ten double values and print their sum. Spaces or newlines may separate values.

Sample correction: the ten numbers printed on the teacher’s sheet sum to 43.0, not 42.5. Here next() discards just one invalid token, preserving later values on the same line.

Hint: plan before coding
  1. Start total at 0 and count at 0.
  2. Read one valid double; add it and increment count.
  3. Stop after ten valid values.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        double total = 0;
        int count = 0;
        while (count < 10) {
            while (!input.hasNextDouble()) {
                input.next();
                System.out.println("Enter a number:");
            }
            double number = input.nextDouble();
            total += number;
            count++;
        }
        System.out.println(total);

        input.close();
    }
}

6. Repeat a word

Read a word and a repeat count, validate the count, then print the word that many times with spaces.

The sheet does not specify whether zero repeats is valid. This version allows zero and rejects negative counts; a word means one whitespace-separated token.

Hint: plan before coding
  1. Read a word with next().
  2. Check for an integer count.
  3. Repeat the output, counting completed prints.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter a word and a non-negative repeat count:");
        String word = input.next();
        int repeats = -1;
        while (repeats < 0) {
            while (!input.hasNextInt()) {
                input.next();
                System.out.println("Enter an integer count:");
            }
            repeats = input.nextInt();
            if (repeats < 0) {
                System.out.println("Count must be at least 0:");
            }
        }
        int count = 0;
        while (count < repeats) {
            System.out.print(word + " ");
            count++;
        }

        input.close();
    }
}

7. Power using a loop

Read a base and exponent, and evaluate the power by repeated multiplication.

Scope chosen for this beginner solution: integer base and non-negative integer exponent, with valid integer input. Negative exponents and 0^0 are outside this version. long stores larger integers than int, but large powers can still overflow.

Hint: plan before coding
  1. Start result at 1.
  2. Multiply by the base once per iteration.
  3. Stop after exponent multiplications.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        System.out.println("Enter an integer base:");
        int base = input.nextInt();
        System.out.println("Enter a non-negative integer exponent:");
        int exponent = input.nextInt();
        if (exponent < 0 || (base == 0 && exponent == 0)) {
            System.out.println("Use a non-negative exponent; 0^0 is not handled here.");
        } else {
            long result = 1;
            int count = 0;
            while (count < exponent) {
                result *= base;
                count++;
            }
            System.out.println(result);
        }

        input.close();
    }
}

8. Average an unknown number of values

Allow any number of positive integers and print their average when the user finishes.

The sheet does not define how to finish. This version uses 0 as a sentinel. It is not included in the average. total is double to avoid integer-division truncation.

Hint: plan before coding
  1. Choose a stopping signal.
  2. Track both total and count.
  3. Do not count the stopping signal.
  4. Check that count is not zero before division.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        double total = 0;
        int count = 0;
        System.out.println("Enter positive integers; enter 0 to finish:");
        while (true) {
            while (!input.hasNextInt()) {
                input.next();
                System.out.println("Enter an integer:");
            }
            int number = input.nextInt();
            if (number == 0) {
                break;
            }
            if (number > 0) {
                total += number;
                count++;
            } else {
                System.out.println("Use a positive integer, or 0 to finish.");
            }
        }
        if (count > 0) {
            System.out.println(total / count);
        } else {
            System.out.println("No numbers entered.");
        }

        input.close();
    }
}

9. Collatz sequence

Start with a natural number. If even, divide by 2; if odd, multiply by 3 and add 1. Show each step and count iterations until 1.

The claim for every natural number is a conjecture, not a proved fact. The extra overflow and iteration guards are safeguards beyond the core classroom algorithm. Long.MAX_VALUE is the largest long value; practise first with small numbers.

Hint: plan before coding
  1. Validate a positive starting integer.
  2. Keep applying one rule while the value is not 1.
  3. Count transformations, not the initial value.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int start = 0;
        while (start < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            start = input.nextInt();
            input.nextLine();
        }
        long number = start;
        int steps = 0;
        while (number != 1 && steps < 10000) {
            if (number % 2 == 0) {
                number /= 2;
            } else {
                if (number > (Long.MAX_VALUE - 1) / 3) {
                    break;
                }
                number = 3 * number + 1;
            }
            System.out.println(number);
            steps++;
        }
        if (number == 1) {
            System.out.println("Iterations: " + steps);
        } else {
            System.out.println("Stopped at a safety limit before reaching 1.");
        }

        input.close();
    }
}

10b. Odd and even digits

Count odd digits and even digits in a positive integer.

Hint: plan before coding
  1. Extract one digit with % 10.
  2. Use digit % 2 to classify it.
  3. Remove the digit.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        int odd = 0;
        int even = 0;
        while (num >= 1) {
            int digit = num % 10;
            if (digit % 2 == 0) {
                even++;
            } else {
                odd++;
            }
            num /= 10;
        }
        System.out.println("Odd: " + odd);
        System.out.println("Even: " + even);

        input.close();
    }
}

10d. Three consecutive ascending digits

Determine whether the number contains three adjacent digits that increase by 1 from left to right.

Interpretation: consecutive integers means a step of exactly 1, such as 123 or 678; 135 and 890 do not qualify. % 10 extracts right to left, so take care to test the original left-to-right order.

Hint: plan before coding
  1. Inspect the last three digits if at least three remain.
  2. Check left + 1 = middle and middle + 1 = right.
  3. Remove one digit to slide the window; stop on a match.
Show reference solution
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);

        int num = 0;
        while (num < 1) {
            System.out.println("Enter an integer at least 1:");
            while (!input.hasNextInt()) {
                input.nextLine();
                System.out.println("Please enter an integer:");
            }
            num = input.nextInt();
            input.nextLine();
        }
        boolean found = false;
        while (num >= 100) {
            int right = num % 10;
            int middle = (num / 10) % 10;
            int left = (num / 100) % 10;
            if (left + 1 == middle && middle + 1 == right) {
                found = true;
                break;
            }
            num /= 10;
        }
        System.out.println(found);

        input.close();
    }
}

Final exam-prep checklist

Prepare on paper

Your upcoming assessment has Part A, Part B and Part C and is handwritten. The question types and marks for those parts have not been confirmed here.
