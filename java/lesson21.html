1. Plan a small task before its syntax

Kevin: a method is a named task you can use again. Before writing its header, answer three questions: What does it do? What information does it need? What result should it give back?

For triangleArea: calculate a triangle area; receive base and height; return a double. For printHello: print a greeting; receive nothing; return no value.

  1. Try one example by hand: base 6, height 8 gives area 24.
  2. Choose the parameters and return type.
  3. Write the calculation or decision in the body.
  4. Call it from main and check the result.

Methods help reuse work, give a program a readable structure and let you test one task at a time. You already use methods such as println(), nextInt() and hasNextInt().

Watch a method run

Think of a method as a small task with a name: inputs → work → result. Follow one call before memorizing the syntax.

Remember: arguments are the values sent in the call; parameters are the named variables receiving them. return gives a value back. println displays a value.

Quick check: remove println — what appears?

Nothing. getSum still calculates and returns 8, and answer still stores 8. Returning a value does not display it.

The two code panels show methods inside the same class Main. Both methods belong alongside each other, not inside each other.

2. Declare it once; call it when needed

public class Main {
    public static void main(String[] args) {
        int answer = getSum(5, 3);
        System.out.println(answer); // 8
    }

    public static int getSum(int first, int second) {
        int sum = first + second;
        return sum;
    }
}

The declaration describes the task; getSum(5, 3) calls it. A helper belongs inside the class, alongside main, not inside main. Its position above or below main does not determine when it runs.

Header partMeaning in this course

Use public static for these Unit 2 helpers, as your teacher requests. Java supports other kinds of methods later. Lower camel case (such as triangleArea) is a naming convention, not a compiler requirement. Parentheses are required in these declarations and ordinary calls.

3. Parameters, arguments and local variables

Parameters are the variables in the declaration: first and second. Arguments are the actual values in the call: 5 and 3. Match the number, order and compatible types of arguments.

  1. main evaluates the arguments.
  2. getSum receives first = 5 and second = 3.
  3. The method calculates sum = 8.
  4. return sends 8 back to the call.
  5. main stores it in answer and prints it.

A parameter or local variable only exists in its method/block scope. Java passes values: changing an int parameter does not change the caller’s original int.

public static void change(int value) {
    value = 99;
}
// Inside main:
int number = 5;
change(number);
System.out.println(number); // still 5

A method expecting double can accept an int by widening conversion. A method expecting int cannot accept a double without an explicit conversion; converting would discard a fractional part, so only do it intentionally.

4. Returning is different from printing

Method kindCallResult
void, no parametersprintHello();Performs a task; no value to store.
void, with parametersprintName("Kevin");Prints using supplied text.
Return value, no parametersString text = messageGenerator();Returns text to the caller.
Return value, with parametersint area = calcArea(2, 3);Returns the calculated value 6.
public static void displaySum(int a, int b) {
    System.out.println(a + b);
}
public static int getSum(int a, int b) {
    return a + b;
}
// Inside main:
displaySum(5, 3);              // prints 8
int answer = getSum(5, 3);    // stores 8; prints nothing
System.out.println(answer);  // now prints 8

return exits the method immediately, not just its loop. A non-void method must return a compatible value on every path that completes normally. A void method may use return; to end early, but cannot return a value. You cannot assign or print the result of a void method.

You may store a returned value, print it directly, or use it in another expression. Simply writing getSum(5, 3); calls the method but discards its return value.

Show gcf
public static int gcf(int n, int p) {
    int divisor;
    if (n < p) {
        divisor = n;
    } else {
        divisor = p;
    }
    while (divisor > 0) {
        if (n % divisor == 0 && p % divisor == 0) {
            return divisor;
        }
        divisor--;
    }
    return 1;
}
Show calcCircleArea
public static double calcCircleArea(int radius) {
    return Math.PI * radius * radius;
}

textRepeater("Hello", 4) returns "Hello Hello Hello Hello " with a trailing space. The gcf method starts at the smaller positive number and searches downward, so the first common factor is the greatest. gcf(256, 300) = 4; gcf(1256, 23452) = 4. Its classroom contract is two positive integers; do not apply this version to zero or negatives.

6. triangleArea(double base, double height)

Return the triangle area as double.

Plan before coding

Receive base and height; multiply them; divide by 2; return the result.

Show beginner reference method
public static double triangleArea(double base, double height) {
    return base * height / 2;
}

Test: 6, 8 → 24.0; 3, 5 → 7.5.

The double parameters make the division decimal arithmetic. Assume ordinary nonnegative dimensions.

7. average(int n1, int n2, int n3)

Return the average of three integers as double.

Plan before coding

Add the values using a double total, then divide by 3.

Show beginner reference method
public static double average(int n1, int n2, int n3) {
    double total = n1;
    total = total + n2 + n3;
    return total / 3;
}

Test: 65, 70, 75 → 70.0; 1, 2, 2 → about 1.6667.

A double return type alone does not fix integer division: (1 + 2 + 2) / 3 computes 1 before conversion. Use a double total or divide by 3.0. Initializing total from n1 also avoids int overflow when adding large int values.

8. isDivisible(int num, int div)

Return true when num is divisible by div; otherwise false.

Plan before coding

Guard against a zero divisor; compute the remainder; return whether it equals zero.

Show beginner reference method
public static boolean isDivisible(int num, int div) {
    if (div == 0) {
        return false;
    }
    return num % div == 0;
}

Test: 8, 2 → true; 9, 4 → false; 3, 5 → false; 0, 3 → true.

The worksheet does not define div = 0. This reference returns false for that case to avoid ArithmeticException. Here % calculates a number; == turns the result into a boolean.

9. factorial(int n)

Return n!, or -1 for a negative n.

Plan before coding

Reject a negative n; start product at 1; multiply by 1 through n; return product.

Show beginner reference method
public static int factorial(int n) {
    if (n < 0) {
        return -1;
    }
    int product = 1;
    for (int i = 1; i <= n; i++) {
        product = product * i;
    }
    return product;
}

Test: 5 → 120; 0 → 1; -5 → -1; 12 → 479001600.

For 0 the loop runs zero times, leaving product = 1. This int solution is accurate for 0–12. Beyond 12, overflow means int cannot represent the factorial; use the stated practice domain. The negative sentinel -1 follows the worksheet.

10. strongNumber(int n)

Return whether the number equals the sum of its digits’ factorials.

Plan before coding

Preserve n; extract each digit with % 10; call factorial(digit); add it; remove the digit with / 10; compare sum with n.

Show beginner reference method
public static boolean strongNumber(int n) {
    if (n < 0) {
        return false;
    }
    int remaining = n;
    int sum = 0;
    do {
        int digit = remaining % 10;
        sum = sum + factorial(digit);
        remaining = remaining / 10;
    } while (remaining > 0);
    return sum == n;
}

Test: 145 → true; 123 → false; 1 → true; 2 → true; 0 → false.

145 gives 1! + 4! + 5! = 1 + 24 + 120 = 145. Every digit is at most 9, so the factorial helper remains in its safe int range. A do-while processes 0 once: 0! = 1, so 0 is not strong. This example rejects negative n.

11. size(int n)

Return the number of decimal digits.

Plan before coding

Start count at 1; divide the magnitude by 10 while it has at least two digits; increase count each time.

Show beginner reference method
public static int size(int n) {
    long remaining = n;
    if (remaining < 0) {
        remaining = -remaining;
    }
    int count = 1;
    while (remaining >= 10) {
        remaining = remaining / 10;
        count++;
    }
    return count;
}

Test: 6512 → 4; 9 → 1; 0 → 1; -247 → 3.

The worksheet’s examples mean digit count, despite the phrase “order of magnitude.” This reference counts 0 as one digit and ignores a minus sign. A long copy lets the magnitude of the smallest int be represented safely.

12. armstrongNumbers(int n)

For a positive integer, compare n with the sum of each digit raised to the number of digits.

Plan before coding

Use size(n) for the exponent; extract a digit; multiply it by itself length times; add the power; repeat; compare.

Show beginner reference method
public static boolean armstrongNumbers(int n) {
    if (n <= 0) {
        return false;
    }
    int length = size(n);
    int remaining = n;
    long sum = 0;
    while (remaining > 0) {
        int digit = remaining % 10;
        long power = 1;
        for (int i = 1; i <= length; i++) {
            power = power * digit;
        }
        sum = sum + power;
        remaining = remaining / 10;
    }
    return sum == n;
}

Test: 153 → true; 346 → false; 1 → true; 9474 → true; 0 → false under the worksheet’s positive-integer definition.

153: 1³ + 5³ + 3³ = 153. 346: 3³ + 4³ + 6³ = 307. Strong numbers use factorials; Armstrong numbers use powers. long for sum and power prevents overflow for int inputs. A simple multiplication loop keeps the arithmetic integral; Math.pow returns double.

1. Arguments or parameters?

In triangleArea(6, 8), are 6 and 8 arguments or parameters?

Check answer and explanation

Arguments. The declared variables base and height are parameters.

2. Does return print?

Check answer and explanation

Nothing. result stores 6; a separate print is needed.

int sum2 = getSum(sum, sum);
System.out.println(sum2);
Check answer and explanation

16. The first call returns 8; the second receives 8 and 8 and returns 16.

4. Fix integer division

public static double average(int a, int b, int c) {
    return (a + b + c) / 3;
}

For 1, 2, 2, why does this return 1.0? Fix it.

Check answer and explanation

The expression does integer division first. For ordinary small inputs divide by 3.0; the worksheet reference uses a double total before division, which also avoids overflow in the int addition.

5. Fix a void call

int answer = printHello();
Check answer and explanation

A void method has no result to assign. Call printHello(); on its own.

6. Trace local changes

int n = 4;
change(n); // change assigns 99 to its int parameter
System.out.println(n);
Check answer and explanation

4. The method changes its own parameter copy, not n in main.

7. Match the types

Can calcArea(int length, int width) be called with calcArea(2.5, 3)?

Check answer and explanation

No. The double 2.5 cannot be implicitly narrowed to int. Use appropriate int arguments, or change the method’s contract if decimal dimensions are required.

8. Missing return

public static int bigger(int a, int b) {
    if (a > b) {
        return a;
    }
}
Check answer and explanation

This fails to compile: if a is not greater than b, the method reaches its end without returning an int. Add an else returning b or a return b after the if.

9. Factorial boundary

Why does factorial(0) return 1 instead of 0?

Check answer and explanation

The product starts at 1, and the loop has no iterations when n is 0. That matches 0! = 1.

10. Count digits

Trace size(10865). How many divisions occur?

Check answer and explanation

Four: 10865 → 1086 → 108 → 10 → 1. Count begins at 1 and becomes 5.

11. Early return

In gcf, what does return divisor do when a common factor is found?

Check answer and explanation

It ends the entire gcf method immediately and gives that factor to the caller. Searching downward makes the first match the greatest for positive inputs.

12. Write a helper

Write public static boolean isEven(int n), then call it from main for 7 and print the returned result.

Check answer and explanation
public static boolean isEven(int n) {
    return n % 2 == 0;
}
// Inside main:
System.out.println(isEven(7)); // false

15. Check your method before finishing

  • I can state its task, inputs and output in words.
  • I put helpers alongside main, inside the class.
  • My parameter count, order and types match the call.
  • I know whether the method prints, returns, or does both.
  • Every normally completing path of a non-void method returns a suitable value.
  • I preserve the original number when comparing with processed digits.
  • I tested ordinary and boundary cases, including 0 when relevant.

hoursRem

Show beginner method
    public static int hoursRem(int sec) {

Despite its name, this helper returns total hours; it does not wrap at 24.

convertTime

Plan: Call the helpers, add a leading zero to one-digit values, then concatenate.

Hand check: 7351 → 02:02:31.

Show beginner method
    public static String convertTime(int sec) {
        if (sec < 0 || sec >= 86400) {
            return "Invalid time";
        }
        int hours = hoursRem(sec);
        int minutes = minutesRem(sec);
        int seconds = secondsRem(sec);
        String h = "" + hours;
        String m = "" + minutes;
        String s = "" + seconds;
        if (hours < 10) { h = "0" + h; }
        if (minutes < 10) { m = "0" + m; }
        if (seconds < 10) { s = "0" + s; }
        return h + ":" + m + ":" + s;
    }

The worksheet says 24-hour time but also HH <= 24. This reference uses standard clock hours 00–23 and accepts 0–86399 seconds; otherwise it returns Invalid time. It does not wrap a duration into another day.

solveLinearX

Plan: Rearrange y = slope * x + intercept before coding.

Hand check: x = (y - intercept) / slope; (0 - (-1)) / 4 = 0.25.

Show beginner method
    public static double solveLinearX(double slope, double yIntercept, double yValue) {
        return (yValue - yIntercept) / slope;
    }

Contract: slope is nonzero. With slope 0 there is either no solution or many solutions, not one x.

checkQuad

Plan: Calculate both roots; compare the proposed pair in either order.

Hand check: For x² - 2x - 8 = 0, roots are -2 and 4.

Show beginner method
    public static boolean checkQuad(double a, double b, double c, double x1, double x2) {
        if (a == 0) { return false; }
        double discriminant = b * b - 4 * a * c;
        if (discriminant < 0) { return false; }
        double root1 = (-b + Math.sqrt(discriminant)) / (2 * a);
        double root2 = (-b - Math.sqrt(discriminant)) / (2 * a);
        double tolerance = 0.000001;
        boolean sameOrder = Math.abs(x1 - root1) < tolerance
                && Math.abs(x2 - root2) < tolerance;
        boolean swappedOrder = Math.abs(x1 - root2) < tolerance
                && Math.abs(x2 - root1) < tolerance;
        return sameOrder || swappedOrder;
    }

Require a != 0 and a nonnegative discriminant. Compare decimal roots with tolerance 0.000001 for ordinary classroom values. Checking that each input is some root would incorrectly accept (-2, -2) when two distinct roots exist.
