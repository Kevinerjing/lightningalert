1. Find a prefix

Task: return the text before the first occurrence of a character. Plan: search → check whether found → take the prefix → return.

The worksheet description mentions String then char, but its sample call and solution use charFinder(char c, String str). Follow that signature consistently.

    public static String charFinder(char c, String str) {
        int index = str.indexOf(c);
        if (index == -1) {
            return str;
        }

2. Count a character

Task: count every matching character. Plan: start at 0 → visit each index → compare → increment when matching → return after the entire loop.

Show countChar
    public static int countChar(String str, char c) {
        int count = 0;
        for (int i = 0; i < str.length(); i++) {
            if (str.charAt(i) == c) {
                count++;
            }
        }
        return count;
    }

Use == to compare two char values, but equals to compare String content. count is initialized once before the loop. return belongs after the loop; putting it inside would stop the scan early.

InputResult
countChar("Happy Birthday to you!", 'a')2
countChar("banana", 'a')3
countChar("AAA", 'a')0
countChar("", 'a')0

4. Compare, replace and change case

compareTo: interpret the sign

System.out.println("apple".compareTo("orange")); // -14
System.out.println("cat".compareTo("cat"));      // 0
System.out.println("dog".compareTo("cat"));      // positive

Java compares character values from left to right; the first difference decides. If one String is a prefix of the other, length decides. It is case-sensitive and is not a dictionary sorting rule for every language. Do not test only for -1 or 1: negative, zero, positive are the meaningful categories.

Case and start/end checks

System.out.println("apple".equalsIgnoreCase("Apple")); // true
System.out.println("Happily".endsWith("ly"));          // true
System.out.println("Relax".startsWith("re"));          // false
String word = "Awesome";
System.out.println(word.toLowerCase()); // awesome
System.out.println(word);               // Awesome
word = word.toUpperCase();              // save new text

Replacing text: save the returned String

String text = "Happy Birthday!";
text = text.replace('a', 'A');
System.out.println(text); // HAppy BirthdAy!
System.out.println("Happy Birthday!".replaceAll("Happy", "Good"));

replace uses literal characters/text; replaceAll and replaceFirst interpret regex patterns. For literal text, replace is simpler. For example, replaceAll(".", "x") matches every character, whereas replace(".", "x") replaces literal periods. The slide’s replaceAll expression has an extra closing parenthesis; the runnable version above fixes it.

5. Find and fix the whole program

Find every problem in this attempted character counter. First check compilation, then index safety, then the intended count. Test a match at index 0, several matches, and an empty String.

public static int countChar(String str, char c) {
    int count = 0;
    for (int i = 1; i <= str.length(); i++) {
        if (str.charAt[i] = c) {
            count = +1;
        }
        return count;
    }
}
Reveal corrections
  • charAt[i] → charAt(i): method-call syntax.
  • = → ==: compare the char values.
  • Start i at 0 to include the first character.
  • Use i < str.length() to stay inside the valid indices.
  • count = +1 sets count to positive one; use count++ or count = count + 1.
  • Move return count after the loop: this both allows the entire scan and supplies a return for empty text.
    public static int countChar(String str, char c) {
        int count = 0;
        for (int i = 0; i < str.length(); i++) {
            if (str.charAt(i) == c) {
                count++;
            }
        }
        return count;
    }

Your repeatable checking routine

  1. Read the intended task and write a hand-calculated example.
  2. Check syntax: names, declarations, calls, punctuation and types.
  3. Check runtime risks: empty text, -1 search results, invalid indices.
  4. Check logic: start/end/update, count initialization, return location and every output.

6. Complete handwritten programming task

Write from a blank page: read a full line, read exactly one target character, print its prefix, count its occurrences and print the text vertically.

  1. Inputs: text and a one-character String, then extract its char.
  2. Processing: call charFinder and countChar.
  3. Outputs: print the returned results, then call printVertical.
  4. Repetition: retry the target input until its length is one.
Show full beginner Main.java
import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner input = new Scanner(System.in);
        System.out.print("Enter a line of text: ");
        String text = input.nextLine();
        System.out.print("Enter one character to count: ");
        String target = input.nextLine();
        while (target.length() != 1) {
            System.out.print("Enter exactly one character: ");
            target = input.nextLine();
        }
        char c = target.charAt(0);
        System.out.println("Before first match: " + charFinder(c, text));
        System.out.println("Matches: " + countChar(text, c));
        System.out.println("Text vertically:");
        printVertical(text);
        input.close();
    }

    // Policy when absent: return the whole original string.
    public static String charFinder(char c, String str) {
        int index = str.indexOf(c);
        if (index == -1) {
            return str;
        }
        return str.substring(0, index);
    }
    public static int countChar(String str, char c) {
        int count = 0;
        for (int i = 0; i < str.length(); i++) {
            if (str.charAt(i) == c) {
                count++;
            }
        }
        return count;
    }
    public static void printVertical(String str) {
        for (int i = 0; i < str.length(); i++) {
            System.out.println(str.charAt(i));
        }
    }
}

Download complete Main.java. Compile with javac Main.java, then run java Main. nextLine reads spaces too. If a program first uses nextInt, consume its remaining line ending before the next text nextLine.

Try text banana and target a: prefix b; matches 3; vertical output b, a, n, a, n, a on six lines. Try empty text and a: empty prefix; matches 0; no vertical characters.

7. Eight paper checks

1. Where should return count go?

Check answer

After the loop, so all characters are visited.

2. Why i < str.length(), not <=?

Check answer

The last valid charAt index is length() - 1.

3. Does toUpperCase change the original variable automatically?

Check answer

No. Assign the returned String to save it.

4. Does compareTo return only -1, 0 or 1?

Check answer

No. Interpret the sign.

5. What happens when indexOf finds the target at position 0?

Check answer

substring(0, 0) returns an empty String.

6. What are the countChar results for AaA with targets A and a?

Check answer

2 and 1, because matching is case-sensitive.

7. Why must count not reset inside the loop?

Check answer

Resetting loses earlier matches.

8. What does break in a character loop exit?

Check answer

The nearest loop, not the entire method or program.
